## Publication boundary

The public tree contains original application/UI source, tests, approved scripts, the CRE source/config/lockfile, documentation and CI configuration. It excludes local databases, cache/dependency directories, compiler binaries, generated bundles, raw acquisition records, internal review plans, private paths and account credentials. Previous local reference records remain separate.

Fixture data is synthetic. Actual GitHub CI is identified by its real repository/commit/run/attempt/workflow/blob and endpoint receipts. CRE remains compiled-only. Modeled local acceptance is never described as customer acceptance.

No project-wide reuse license has been selected. Dependency code is not vendored or relicensed; see [dependency notices](DEPENDENCIES.md).
